## §1 — Preflight (auto, all BLOCKING)

The audit C3 finding split A2 into **A2 (pre-bump auth-only)** and **A2' (post-bump full dry-run)**. A5 anchor uses the version-bump commit SHA, not a non-existent git tag.

```bash
# A1 — gh auth status (exit 0 required)
gh auth status

# A2 — npm publish --dry-run (PRE-BUMP).
# Validates auth + scope + tarball assembly. Will exit non-zero with
# EPUBLISHCONFLICT because package.json is still 0.15.3 — this is EXPECTED.
# We treat exit-with-EPUBLISHCONFLICT as PASS, exit-with-other as FAIL.
npm_dry_a2() {
  local out
  out=$(npm publish --dry-run 2>&1)
  if echo "$out" | grep -q "Tarball Details"; then
    if echo "$out" | grep -q "cannot publish over the previously published versions"; then
      echo "A2 PASS: auth+scope+tarball assembled; EPUBLISHCONFLICT expected pre-bump."
      return 0
    fi
  fi
  echo "A2 FAIL: dry-run did not assemble tarball; check auth/scope/files glob."
  echo "$out" | tail -20
  return 1
}
npm_dry_a2 || exit 1

# A3 — sv-gate-fast (70/70 required)
zsh tests/sv-gate-fast.sh
[[ $? -eq 0 ]] || { echo "A3 FAIL"; exit 1; }

# A4 — Node test:node (359/359 or higher; 0 fail required)
npm run test:node

# A5 — Self-Verification Gate fire detector. Anchor uses 0.15.3 version-bump
# commit SHA (no v0.15.x git tag exists; npm version --no-git-tag-version policy).
ANCHOR=$(git log --oneline | grep -E "bump version to 0.15.3" | awk '{print $1}' | head -1)
[[ -n "$ANCHOR" ]] || { echo "A5 FAIL: cannot derive anchor commit"; exit 1; }
TRIGGER_DIFF=$(git diff "$ANCHOR..HEAD" -- \
  src/commands/rlp-desk.md \
  src/governance.md \
  src/scripts/init_ralph_desk.zsh)
if [[ -n "$TRIGGER_DIFF" ]]; then
  echo "A5 BLOCK: trigger files changed → run 3-scenario Self-Verification trio first."
  echo "$TRIGGER_DIFF" | head -10
  exit 2
fi
echo "A5 PASS: trigger files unchanged since 0.15.3."
```

## §3 — Post-publish verification (auto, all BLOCKING)

```bash
# P1 — fresh install
npm install -g @ai-dev-methodologies/rlp-desk@0.15.4

# P2 — banner-strip diff (3 ref files)
strip_banner() { tail -n +2 "$1" | grep -v -E '^(<!-- |# |// )DO NOT EDIT' || true; }
for src_path in src/governance.md src/commands/rlp-desk.md src/node/run.mjs; do
  case "$src_path" in
    src/commands/*) installed="$HOME/.claude/${src_path#src/}" ;;
    src/*)          installed="$HOME/.claude/ralph-desk/${src_path#src/}" ;;
  esac
  diff <(cat "$src_path") <(strip_banner "$installed") || { echo "P2 FAIL: $src_path"; exit 1; }
done

# P3 — recursive Node sync
diff -rq src/node "$HOME/.claude/ralph-desk/node" | grep -v 'DO NOT EDIT' \
  | (! grep -q .) || { echo "P3 FAIL: Node tree drift"; exit 1; }

# P4 — chmod 0o444 verify
for f in "$HOME/.claude/ralph-desk/governance.md" \
         "$HOME/.claude/commands/rlp-desk.md" \
         "$HOME/.claude/ralph-desk/node/run.mjs"; do
  mode=$(stat -f '%Lp' "$f" 2>/dev/null || stat -c '%a' "$f")
  [[ "$mode" == "444" ]] || { echo "P4 FAIL: $f mode=$mode"; exit 1; }
done

# P5 — registry-side version confirmation (allow single retry on propagation lag)
for attempt in 1 2 3; do
  observed=$(npm view @ai-dev-methodologies/rlp-desk@0.15.4 version 2>/dev/null)
  [[ "$observed" == "0.15.4" ]] && break
  [[ $attempt -lt 3 ]] && sleep 30
done
[[ "$observed" == "0.15.4" ]] || { echo "P5 FAIL: registry shows '$observed'"; exit 1; }
```

## v0.15.4 — Lifecycle hardening (2026-05-08)

- `RLP_LIFECYCLE_METRICS=1` env flag enables structured telemetry for tmux/process

  - `sentinel_lock_to_unlock_ms` — per-type, lock vs unlock pair
  Default OFF; zero overhead when unset.

### Fixed
- Bug #5/7 done-claim race window. The Worker pane is now reaped
  (`_kill_pane_process`) and the `done-claim.json` sentinel locked
  (`chmod 0o444`) at the moment the leader observes done-claim. Previously the
  pane lingered 30-120s post-write and could revise the artifact. Four

  - `run_ralph_desk.zsh` A4 fallback inline path
  - `run_ralph_desk.zsh` post iter-signal reaper (parallel done-claim lock)
  - `campaign-main-loop.mjs` Node leader worker reap (parallel done-claim lock)

### Strengthened
- Real-LLM SV scenarios bug-05 (worker-dead-on-reuse) and bug-07

  `RLP_LIFECYCLE_METRICS=1`:
