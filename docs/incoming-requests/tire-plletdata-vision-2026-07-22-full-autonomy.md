# rlp-desk 비전 제안 — 완전 자율형(AI-PO)으로의 진화 로드맵 (오너 방향 지시 + 적대 검증 완료) — 2026-07-22

오너 지시 원문 취지: *"rlp-desk는 완전 자율형으로 가야 한다. PRD 구성이 불충분해 발굴형 문제를 식별 못 한 것이 근본이고, PO 역할도 프론티어 모델 페르소나로 위임해 모든 걸 자율주행으로 풀어야 한다. 의심스러운 것은 brainstorm/init 시점에 풀어야 한다."*

이 논제를 pa-foundation 캠페인 1일치 실기록(BLOCKED 12건·PO 개입 전수)으로 **멀티에이전트 적대 검증**(패널 4인 + 사건 원장 + 주장별 독립 반증 12건: CONFIRMED 7/REFUTED 4/PLAUSIBLE 1)한 결과와 그로부터 도출한 설계를 제안한다.

## 1. 검증 결과 요약

| 명제 | 판정 | 실측 |
|---|---|---|
| PO를 AI 페르소나로 위임 | **지지** | 개입 12건 중 AI-PO 처리 가능 5 + 부분 5 / 불가 2 |
| 모든 불확실성을 init에서 선해소 | **문자 그대로는 기각, 정제형 성립** | 9/12는 init 시점에 존재하지 않았음(외부 데이터 변경·CLI 릴리스·도구 회귀·레이스). 선해소 대상은 "불확실성"이 아니라 **"불확실성 대응 프로토콜"** |
| 완전 자율주행 | **도달 가능** | 잔여 인간 필수 2건 중 1건(시스템 권한)은 도구 성숙으로 소멸, 1건(외부 사실)은 비동기 채널로 우회 |

핵심 CONFIRMED 3건:
- **외부 사실은 어떤 모델로도 대체 불가**: cohort 57행 사건에서 필요한 것은 판단력이 아니라 "scraper 팀의 작업 의도"라는 저장소 밖 사실이었다. AI-PO가 자체 판정하면 fake-truth 비가역 리스크.
- **halt-and-classify가 인간의 유일한 실기여였다**: 341이 정답인데 워커는 우선순위 체인을 정직하게 지켜 398 오답 정지를 냈다(blocked-39). 인간은 "이건 external-fact 계열"이라는 분류만 했다 — 그 분류 채널이 시스템에 없다.
- **감독 회귀 실재**: 모든 게이트는 워커/done-claim을 감사하지만 **PO의 계약 편집을 감사하는 층이 없다** — PO 산출 341 매니페스트 v1의 로케일 오염(0ff72f4, 폐기)이 실증. AI-PO로 바꿔도 이 구멍은 그대로다.

주의(정직 고지): 옹호 패널의 "12건 중 1건만 인간 필요" 주장은 검증에서 **증거 조작으로 REFUTED** — 적대 검증 없이는 낙관 과대 보고가 났을 것이다. 이 제안서의 수치는 반증 생존분만 사용.

## 2. 단계적 자율성 레벨 (승격 조건 포함)

- **L0 (현재)**: 사람-PO 상주. 오늘 하루 개입 12건.
- **L1 — infra 전결**: AI-PO(또는 러너 자체)가 infra_failure 분류·센티널 처분·재기동·레이스 복구를 전결. *승격 조건: BLOCKED sidecar의 recoverable/suggested_action 필드 기반 자동 소비 + 같은 실패 N회 시 에스컬레이션 규칙.* 오늘 기준 개입 ~60% 흡수.
- **L2 — 계약 개정 전결**: AI-PO가 계약 갭 감지→PRD/test-spec/스플릿/원장 동기 개정까지 전결. *승격 조건(필수): PO-산출물 기계 게이트 — ①문서 3자 정합 lint(PRD·test-spec·per-US 스플릿·정본 파일 교차 검사) ②바이트-결정론 규칙(LC_ALL=C 등) ③개정 감사 체인(append-only, 현행 계약 #19 방식의 일반화 — 이미 부분 실재 확인됨).* 오늘 기준 인간 개입 1건(외부 사실)으로 축소.
- **L3 — 완전 자율**: external-fact 계약 갭에서 정지하지 않음 — **오너 사실-질의 비동기 채널**: 해당 US를 후순위로 돌리고 질의를 큐에 넣고 항해 지속, 오너 응답 도착 시 재편입. *승격 조건: fact-query 프로토콜 + 질의 응답의 계약 반영 자동화.* governance의 "human-in-the-loop 채널 금지" 철학과 정합하려면 이 채널은 "결정 요청"이 아니라 **"사실 응답"**으로 좁게 설계해야 한다 (결정은 여전히 AI-PO가, 사실만 사람이).

## 3. AI-PO 페르소나 명세 (4층 — "깎아야 할 것")

도구가 generic 하네스를 제공하고, 프로젝트가 지식 오버레이를 얹는 이원 구조를 제안한다.

**도구측 (rlp-desk가 제공)**
1. **헌장 = 권한 티어**: 전결(infra·pane·재기동·계약 전파) / 조건부 전결(계약 개정 — 자기-게이트 통과 시만 커밋) / 금지(외부 사실 자체 판정, 정본 삭제, 검증 fail의 런타임 우회 — ledger-seed의 "라우팅 전용, pass 부여 없음" 원칙의 일반화).
2. **자기-게이트**: PO 산출물 전용 pre-gate (위 L2 조건 3종). "감사자가 없는 편집자 금지"를 PO층까지 확장.
3. **fact-query 채널**: conflict-log(현재 record-only 확인됨)를 질의-응답 구조로 확장 + US 후순위 재스케줄.
4. **에스컬레이션 상수**: 같은 유형 실패 N회(기본 3) → 사람 보고. 오늘 워커 pane 4연속 재시도에서 이 규칙이 자동으로 걸리지 않았음이 원장에 기록돼 있다.

**프로젝트측 (캠페인 오버레이 — pa-foundation에서 이미 축적된 실물)**
- 독트린: BLOCKED 원인 3분류, 계약 주입 규율(라인-교체+grep 검증), 재기동 표준절차, 원장·시드 취급.
- 도메인 지식: 보호 경로, 데이터 계약(cohort 정본·앵커), 오너-사실 목록(어떤 질문이 external-fact인지의 사례집).

## 4. brainstorm/init 강화 게이트 (오너 지적 "PRD 구성 자체가 불충분했다"의 구체화)

1. **데이터 의존성 스냅샷 동결**: 실데이터에서 파생된 모든 AC 상수(카운트·앵커)는 스냅샷 ID로 참조 + "외부 변경 시 재기준 절차"를 계약에 내장 — 오늘의 341 사가를 통제된 이벤트로 바꿈.
2. **외부 시스템 변경 예고 수집**: 캠페인 기간 중 공유 자원(dev DB 등)을 만지는 타 프로젝트의 예정 작업을 init에서 질의·기록.
3. **US 분류 게이트 기계화(IL-2¾ 강화)**: 명세형/발굴형/검증형 분류를 필수화하고, 검증형에는 RED-불가 독트린 대체 게이트를 자동 배정 (오늘 US-000/001 독트린 벽의 근본 봉인).
4. **증거 스키마 선언**: done-claim의 AC별 라벨 스키마를 init 산출물에 포함 (형식 트집 라운드 선제 소거).
5. **환경 계약**: CLI 버전 고정/업데이트 프롬프트 무력화 등 실행 환경 전제를 init에서 검증 (0.145.0 다이얼로그 사건의 계열 봉인).

## 5. 우선순위 제안
